# ORION — LANDING PAGE VISUAL REWORK
## Transform the existing landing page into an immersive 3D intelligence experience

You are working on the EXISTING ORION landing page.

The current implementation already has:

- ORION navigation
- hero typography
- tagline
- description
- CTA buttons
- status HUD cards
- dark visual theme

DO NOT throw away the existing page.

We are now changing the visual concept of the landing page.

The current page is too empty on the right side and feels like a conventional SaaS landing page.

We want to transform it into an immersive, cinematic, scroll-driven 3D cybersecurity intelligence experience.

==================================================
1. CORE CONCEPT
==================================================

The landing page should tell a visual story:

OBSERVE
   ↓
DETECT
   ↓
CONNECT
   ↓
CORRELATE
   ↓
UNDERSTAND
   ↓
RESPOND

The central visual metaphor is:

A 3D Earth / globe representing the digital environment.

As the user scrolls:

1. The camera slowly approaches the globe.
2. Digital signal points begin appearing.
3. Individual points begin glowing.
4. Signals connect to each other.
5. Related signals form networks.
6. The network becomes increasingly complex.
7. The globe gradually becomes less important.
8. The intelligence network becomes the dominant visual.
9. The scene transitions naturally into ORION's intelligence pipeline.

The scroll itself should feel like the user is progressively entering ORION's intelligence system.

This is the most important visual concept of the entire landing page.

==================================================
2. IMPORTANT — DO NOT MAKE IT A GENERIC GLOBE
==================================================

Do NOT simply place a rotating Earth on the right side.

The globe must communicate:

DIGITAL SIGNALS
+
RELATIONSHIPS
+
CORRELATION
+
THREAT INTELLIGENCE

The Earth is the substrate.

The network is the story.

The intelligence relationships are the hero.

==================================================
6. THE GLOBE
==================================================

Create a stylized technical Earth.

Visual characteristics:

- dark Earth surface
- subtle illuminated continents
- cyan/blue atmospheric rim
- subtle grid/longitude/latitude geometry
- faint glow
- sparse technical particles
- subtle stars/background particles
- no photorealistic Google Earth appearance

The globe should look like:

CYBER INTELLIGENCE VISUALIZATION

not:

SPACE WEBSITE

Do NOT use an excessive space aesthetic.

Cybersecurity remains the dominant identity.

==================================================
7. DIGITAL SIGNAL NODES
==================================================

Place points around the globe.

These represent abstract digital signals.

Potential categories:

PHISHING
WEBSITE
IDENTITY
MEDIA
AUTHENTICATION
TECHNICAL

Do not imply these are actual live global incidents.

They are visual representations of ORION's signal domains.

At initial page load:

Only a SMALL number of nodes should be visible.

For example:

3–5 primary nodes.

The globe should feel relatively quiet.

==================================================
8. SCROLL-DRIVEN STORY
==================================================

THIS IS THE MOST IMPORTANT IMPLEMENTATION.

The 3D scene must react to page scroll.

Do NOT simply animate the globe continuously regardless of scrolling.

Scroll progress should drive the main camera and network state.

Conceptually:

scrollProgress = 0
    ↓
camera far
few nodes
minimal connections

scrollProgress = 0.25
    ↓
camera closer
more nodes
first connections appear

scrollProgress = 0.50
    ↓
camera closer
network expands
more relationships become visible

scrollProgress = 0.75
    ↓
camera enters the network
connections become dominant
globe fades into background

scrollProgress = 1
    ↓
network resolves into ORION intelligence pipeline

Use smooth interpolation.

Avoid sudden jumps.

==================================================
9. CAMERA MOVEMENT
==================================================

At the top:

Camera is relatively far from the globe.

As the user scrolls:

Camera gradually approaches.

The camera should not simply move directly forward.

Add subtle controlled lateral/orbital movement.

For example:

- slight horizontal shift
- subtle rotation
- small parallax
- controlled orbital movement

The effect should feel cinematic.

NOT like a game camera.

Do not make users dizzy.

==================================================
10. NODE ACTIVATION
==================================================

Nodes should progressively activate as the user scrolls.

Example:

STAGE 1:

●      ●
    🌍
       ●

STAGE 2:

●────●
 \   |
  \ 🌍
   \ |
    ●

STAGE 3:

●────●────●
│  ╲ │ ╱  │
│   ╲│╱   │
●────●────●

The connections should be animated.

Do not reveal all connections at once.

==================================================
11. CONNECTION ANIMATION
==================================================

Connections should look like information travelling between signals.

Use:

- curved arcs
- thin glowing lines
- particles travelling along lines
- occasional pulses

Example:

NODE A ●───────→● NODE B

A small light particle travels from A to B.

The movement should be subtle.

Avoid making every line continuously animated.

That would become visual noise.

21. BACKGROUND
==================================================

Keep the background dark.

But do NOT make it completely flat black.

Introduce subtle depth:

- very faint gradient
- technical grid
- sparse particles
- soft atmospheric glow around the globe
- subtle radial illumination

The background should remain dark enough that the globe becomes the visual anchor.

Avoid large bright gradients.

==================================================
22. MOUSE INTERACTION
==================================================

Add subtle mouse interaction.

The globe should respond slightly to cursor movement.

Examples:

- tiny camera parallax
- slight globe rotation influence
- subtle node depth shift

Do not make the entire page move dramatically.

The user should feel depth without losing stability.

==================================================
23. REDUCED MOTION
==================================================

Support:

prefers-reduced-motion

When enabled:

- disable camera travel
- disable particle travel
- reduce globe rotation
- remove aggressive transitions
- preserve static network visualization
- preserve all content

The page must remain understandable.

==================================================
24. MOBILE
==================================================

Do NOT attempt to render the full desktop scene on mobile.

On mobile:

- reduce globe size
- reduce node count
- reduce particle count
- simplify connection network
- reduce camera movement
- keep text readable
- prevent horizontal overflow

The globe remains important but must not destroy usability.

==================================================
25. PERFORMANCE
==================================================

The 3D scene must be GPU-conscious.

Avoid:

- enormous textures
- massive particle systems
- high-poly Earth models
- expensive post-processing everywhere
- unnecessary React state updates
- continuous expensive calculations

Use procedural/lightweight geometry where practical.

Use animation frames efficiently.

Do not sacrifice page usability for visual effects.
